# Airbnb Listings Market Analysis Using Tableau

## Project Overview

This project focuses on analyzing Airbnb listing data to uncover valuable business insights related to pricing strategies, room-type distribution, neighborhood performance, and property availability.

Using Tableau, an interactive dashboard was developed to transform raw Airbnb data into meaningful visualizations that support data-driven decision-making for hosts, property managers, and business stakeholders.

---

## Business Problem

The Airbnb marketplace contains thousands of listings with varying prices, room types, and availability patterns.

Understanding these factors is essential for:

- Optimizing pricing strategies
- Identifying profitable locations
- Improving occupancy rates
- Understanding customer preferences
- Supporting investment decisions

This project aims to analyze Airbnb listing data and provide actionable insights through visual analytics.

## Key Insights

### Pricing Trends
Premium neighborhoods consistently command higher listing prices than average market locations.

### Room Type Performance
Entire homes and apartments generate significantly higher average revenue compared to shared accommodations.

### Market Concentration
A small number of neighborhoods contribute a large percentage of total listings.

### Availability Patterns
Properties with balanced availability tend to attract more customer engagement.

### Revenue Opportunities
High-demand locations present stronger earning potential for hosts and investors.
